# P04. Аналитический SQL

Ответы на три бизнес-вопроса из паспорта обычным SQL + эталон главной метрики.  
Работает на базе из P03 (`../P03/retail.duckdb`).

## Структура

```text
P04/
├── sql/
│   ├── analytics.sql          # запросы на 3 вопроса паспорта
│   └── canonical_metric.sql   # эталон главной метрики + доля утилизации
├── run_analytics.py           # прогоняет оба файла, пишет вывод
├── analytics_output.txt       # сохранённый вывод
├── passport.md                # паспорт с обновлёнными разделами 6–7
└── README.md
```

## Вопрос → запрос

| Вопрос | Факт | Что использовано |
|--------|------|------------------|
| 1. Лучший отдел по выручке в каждом квартале 2024 | продажи | `GROUP BY`, окна `RANK()` и `SUM() OVER` (доля) |
| 2. Где больше всего теряем на утилизации, по какой причине, какая доля от закупки | утилизация + поставки | CTE, окна `SUM() OVER` и `ROW_NUMBER()` |
| 3. Сколько едет товар на каждом транспорте и какая часть закупки в холодильнике | поставки | `date_diff`, `AVG`, `SUM() OVER ()`, `SUM() FILTER` |

Вопрос 2 сравнивает два факта — утилизацию и поставки — через общий справочник товаров.

## Главная метрика

```sql
SELECT SUM(line_total) AS revenue
FROM fact_receipt_line;
```

Значение: **15 383 068.36**.  
Вспомогательная: доля утилизации от закупки — **3.39 %** (425 223.01 / 12 542 717.29).
