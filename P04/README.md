# P04. Аналитический SQL

Ответы на три бизнес-вопроса из паспорта обычным SQL + эталон главной метрики.  
Работает на базе из P03 (`../P03/retail.duckdb`).

## Структура

```text
P04/
├── sql/
│   ├── analytics.sql          # 3 запроса = 3 вопроса паспорта
│   └── canonical_metric.sql   # эталон главной метрики (выручка)
├── run_analytics.py           # прогоняет оба файла, пишет вывод
├── analytics_output.txt       # сохранённый вывод
├── passport.md                # паспорт с обновлённым разделом 6–7
└── README.md
```

## Вопрос → запрос

| Вопрос | Что использовано |
|--------|------------------|
| 1. Лучший отдел по выручке в каждом квартале 2024 | `GROUP BY`, окна `RANK()` и `SUM() OVER` (доля) |
| 2. Выручка лояльных и нелояльных клиентов по магазинам | `GROUP BY`, `SUM() FILTER` |
| 3. Доля оплат через СБП по месяцам | `GROUP BY`, окно `LAG()` |

## Главная метрика

```sql
SELECT SUM(line_total) AS revenue
FROM fact_receipt_line;
```

Значение: **15 383 068.36**.

## Как запустить

```bash
cd P03 && python load_data.py      # если база ещё не создана
cd ../P04 && python run_analytics.py
```

Вывод — в `analytics_output.txt`.
