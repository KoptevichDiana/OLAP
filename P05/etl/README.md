# etl

`load_data.py` — загрузка CSV → DuckDB с проверками. Запуск из папки `P05/`: `python etl/load_data.py`.

**Что чистим при повторе:** перед заливкой полностью очищаем все таблицы витрины (сначала `fact_receipt_line`, потом справочники) и заполняем их заново из CSV, поэтому второй прогон даёт те же строки и ту же выручку, а не вдвое больше.
