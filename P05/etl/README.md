# etl

`load_data.py` выполняет полный ELT-процесс для модели P03:

1. читает 10 CSV в `stg_*`;
2. проверяет обязательные поля, диапазоны, даты, дубли, связи и календарь;
3. при ошибках останавливается до изменения витрины;
4. при успешных проверках в транзакции пересоздаёт витрину и загружает справочники раньше фактов;
5. сверяет количества и суммы с исходными CSV.

Запуск из корня `P05`:

```bash
python etl/load_data.py
python etl/load_data.py
python etl/load_data.py data/bad
```

**Повторная загрузка:** таблицы витрины пересоздаются в транзакции и заполняются заново. Второй прогон поэтому даёт те же количества и суммы, а не удваивает факты. Лог всех запусков записывается в `run_log.txt`.
