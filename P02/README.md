## Схема «звезда» (P02)

В центре — таблица фактов `fact_receipt_line` (строки чеков). Вокруг неё — 5 справочников.

**Одна строка в `fact_receipt_line` = одна строка чека** (ключ: `receipt_line_id`).

Картинка схемы — `star.png`.

### Таблицы

| Таблица | Откуда | Что внутри |
|---------|--------|------------|
| `fact_receipt_line` | `fact_receipt.csv` | продажи: когда, кто, какой товар, в каком магазине, сколько, по какой цене, как оплатил |
| `dim_goods`      | `dim_goods.csv`   | товары (название, отдел, производитель, ед. изм., цена по прайсу, поставщик) |
| `dim_client`     | `dim_client.csv`  | клиенты (имя, пол, год рождения, город, лояльность, дата регистрации) |
| `dim_shop`       | создаём сами      | магазины 1–12 (название, город, формат) |
| `dim_calendar`   | генерируем из `sold_at` | календарь (год, квартал, месяц, день недели, выходной) |
| `dim_pay_method` | из значений `pay_method` | способы оплаты: карта, наличные, СБП, подарочная карта |

### Связи

| Поле в факте | Куда ведёт |
|--------------|------------|
| `sku_id`        | `dim_goods.sku_id` |
| `client_id`     | `dim_client.client_id` |
| `shop_id`       | `dim_shop.shop_id` |
| `pay_method_id` | `dim_pay_method.pay_method_id` |
| `sold_at` (дата)| `dim_calendar.date_key` |

### Что считаем

- `line_total` — выручка по строке
- `qty` — количество (шт или кг — смотреть `measure_unit`)
- `sell_price` — фактическая цена за единицу (не суммируется)
- скидка = (`list_price` − `sell_price`) × `qty`
